## TB1 – Sprint Review (Semana 7)

Durante la elaboración de la entrega **TB1**, el equipo corrigió las observaciones de la AV1 en el informe y desarrolló el Sprint 2, centrado en la implementación de la Web Application de PulsePower en Angular. El trabajo se distribuyó por bounded context, de modo que cada integrante implementó sus módulos y los integró en la rama develop mediante commits propios. Además, se desplegó en Render una API simulada con datos del wearable, que la Web Application consume. Uno de los integrantes no registró aportes en esta entrega, por lo que su parte se redistribuyó entre los demás.

| **Integrantes** | **Actividades realizadas en el informe, la Web Application y la presentación** |
| --- | --- |
| **Evangelista Ygnacio, Sergio Joaquin** | Implementó en la Web Application los bounded contexts Physiology (página de recuperación), Wellness (check-ins, hábitos y ejercicios de respiración) y Sleep (registros y rutina de sueño). En el informe, actualizó los Hypothesis Statements y el contenido del Capítulo I, los resúmenes de entrevistas y los perfiles de segmentos del Capítulo II, y revisó la especificación de requisitos del Capítulo III. |
| **Viza Quispe, Marlon Packard** | Desarrolló la base de la Web Application en Angular: configuración del proyecto, shell de la aplicación, tema y estilos globales, servicios y adaptadores compartidos, componentes de UI comunes y catálogos de traducción ES/EN; además, implementó los primeros DTOs del bounded context Training. En el informe, actualizó el Capítulo IV con los diagramas de arquitectura de software, el diseño orientado a objetos (Class Diagrams por bounded context), el diseño de base de datos y la sección de planes; también revisó los bounded contexts del Capítulo II y finalizó las conclusiones. |
| **Osorio Ramirez, Eduardo Jesus** | Implementó la API simulada de datos del wearable con JSON Server y la desplegó en Render; integró la Web Application con esa API mediante un adaptador HTTP en el bounded context Physiology, y desarrolló los módulos Training y Reports y las rutas de la aplicación. En el informe, extendió el Big Picture EventStorming y el Ubiquitous Language a los siete bounded contexts, corrigió la matriz de trazabilidad y el rango de edad del segmento 2, añadió la trazabilidad de Business Goals a User Stories (Capítulo III) y de User Stories a vistas y flujos (Capítulo IV), unificó los nombres de los bounded contexts en los Capítulos II, IV y V y completó la tabla de Aspect Leaders and Collaborators. |
| **Martin Farro, Alexis Sebastian** | Implementó en la Web Application los bounded contexts IAM (inicio de sesión, registro, configuración y suscripción) y Community (rachas, logros y avance compartido). En el informe, corrigió las User Stories del Capítulo III, añadió wireflow diagrams y user goals al Capítulo IV y redactó el Sprint 2 del Capítulo V: Sprint Planning, Sprint Backlog con el tablero de Trello y las evidencias de desarrollo y de despliegue. |
| **Carbajal Santivañez, Sebastian Aaron** | No registra aportes en el repositorio del informe ni en el de la Web Application durante esta entrega. |
